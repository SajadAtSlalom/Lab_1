# Resources Directory

This directory contains shared resources, reference materials, and helpful guides for all students.

## 📚 What Goes Here?

- Reference documentation
- Tutorial links
- Example code (non-assignment specific)
- Helpful guides and cheat sheets
- Dataset files
- Configuration examples
- Libraries or tools information

## 🗂️ Suggested Organization

```
resources/
├── documentation/
│   └── getting_started.md
├── examples/
│   └── sample_code.py
├── datasets/
│   └── data.csv
├── tutorials/
│   └── git_basics.md
└── README.md (this file)
```

## 📝 How to Contribute Resources

Anyone can add helpful resources to this directory:

1. **Create appropriate subdirectories** if needed
2. **Add your resource** with clear naming
3. **Include a description** in the file or a nearby README
4. **Commit with a descriptive message**:
   ```bash
   git add resources/
   git commit -m "Add Python tutorial resource"
   git push
   ```

## ⚠️ Guidelines

- **Relevance**: Only add resources related to the course
- **Attribution**: Credit original authors
- **Quality**: Verify resources are accurate and helpful
- **Organization**: Keep the directory well-structured
- **No plagiarism**: Don't upload copyrighted material without permission
