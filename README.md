# Lab_1 - Student Work Sharing Repository

Welcome to Lab_1! This repository is designed for students to share and collaborate on their lab work.

## 📁 Repository Structure

```
Lab_1/
├── students/           # Student work directory
│   └── README.md      # Instructions for students
├── resources/         # Shared resources and materials
│   └── README.md
├── templates/         # Templates for student submissions
│   └── README.md
└── README.md          # This file
```

## 🚀 Getting Started

1. **Fork or Clone** this repository to your local machine
2. **Navigate** to the `students/` directory
3. **Create** a folder with your name or student ID (e.g., `students/john_doe/`)
4. **Add** your work to your personal folder
5. **Commit** and **push** your changes
6. **Create a Pull Request** if contributing to the main repository

## 📝 Submission Guidelines

- Each student should create their own folder under `students/`
- Keep your work organized within your personal folder
- Use descriptive file names and comments in your code
- See [CONTRIBUTING.md](CONTRIBUTING.md) for detailed contribution guidelines

## 🤝 Collaboration

- Feel free to review and learn from other students' work
- Be respectful of others' contributions
- Follow the code of conduct and academic integrity policies

## 🔧 Templates

The `templates/` directory contains starter templates for common assignments. Copy these to your personal folder to get started quickly.
