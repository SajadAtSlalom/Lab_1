# Templates Directory

This directory contains starter templates for common assignments and projects. Use these templates to quickly get started with your work.

## 📋 Available Templates

Templates will be added here as they become available for different assignments.

## 🚀 How to Use Templates

1. **Browse available templates** in this directory
2. **Copy the template** to your personal folder in `students/your_name/`
3. **Rename and modify** the template for your assignment
4. **Follow the instructions** within each template

### Example Usage

```bash
# Copy a template to your folder
cp -r templates/python_assignment students/your_name/assignment1

# Navigate to your folder
cd students/your_name/assignment1

# Start working on the template
# Edit files, add your code, test, and commit
```

## 📁 Template Structure

Each template may include:
- Starter code files
- README with instructions
- Configuration files
- Test files
- Documentation structure

## ✍️ Contributing Templates

Instructors and TAs can add new templates:

1. **Create a new directory** with a descriptive name
2. **Add starter files** and structure
3. **Include a README** with clear instructions
4. **Commit and push**:
   ```bash
   git add templates/new_template/
   git commit -m "Add new_template for Assignment X"
   git push
   ```

## 📝 Template Guidelines

Good templates should:
- ✅ Have clear, commented code
- ✅ Include a README with instructions
- ✅ Provide a solid starting point
- ✅ Follow best practices
- ✅ Be well-organized
