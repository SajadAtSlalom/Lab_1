# Python Assignment Template

This is a starter template for Python programming assignments.

## 📋 Contents

- `main.py` - Main program file with starter code
- `tests.py` - Unit tests template (optional)
- `requirements.txt` - Python dependencies (optional)
- `README.md` - This file (customize for your assignment)

## 🚀 Getting Started

1. **Copy this template** to your personal folder:
   ```bash
   cp -r templates/python_assignment students/your_name/assignment_name
   ```

2. **Navigate to your folder**:
   ```bash
   cd students/your_name/assignment_name
   ```

3. **Install dependencies** (if any):
   ```bash
   pip install -r requirements.txt
   ```

4. **Start coding** in `main.py`

5. **Run your program**:
   ```bash
   python main.py
   ```

6. **Run tests** (if applicable):
   ```bash
   python tests.py
   ```
