# Students Directory

This directory is where all students should place their work.

## 📂 How to Use This Directory

Each student should create their own folder here with their name or student ID.

### Example Structure

```
students/
├── john_doe/
│   ├── README.md
│   ├── assignment1/
│   │   └── code.py
│   └── assignment2/
│       └── project.js
├── jane_smith/
│   ├── README.md
│   └── lab1/
│       └── solution.java
└── README.md (this file)
```

## 🚀 Getting Started

1. **Create your folder**:
   ```bash
   mkdir your_name
   cd your_name
   ```

2. **Add a README** describing your work:
   ```bash
   echo "# Your Name's Lab Work" > README.md
   ```

3. **Add your assignments** in organized subdirectories:
   ```bash
   mkdir assignment1
   # Add your code files
   ```

4. **Commit and push your work**:
   ```bash
   git add .
   git commit -m "Add your_name's work"
   git push
   ```

## 📝 Guidelines

- **One folder per student**: Create only one folder with your name
- **Organize by assignment**: Create subdirectories for different assignments
- **Include documentation**: Add README files to explain your work
- **Respect others**: Don't modify other students' folders
- **Keep it clean**: Remove unnecessary files before committing

## 💡 Tips

- Use descriptive folder and file names
- Comment your code thoroughly
- Test your code before submitting
- Include any necessary documentation or instructions
- You can include screenshots, diagrams, or other supporting materials

## 🤝 Collaboration

While each student has their own folder, you can:
- Review other students' code to learn
- Share resources in the `resources/` directory
- Discuss approaches and solutions (while maintaining academic integrity)
